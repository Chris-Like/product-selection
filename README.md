# 选品台 · auto-pick-studio

个人自用的 **Agent Skill / Plugin 包**：本机 Web 页面维护采集网站与登录授权（**不录入密码**），点一次「采集」由 Playwright 自动取数，结果回到同一页面。可安装到 WorkBuddy / Codex，也可以不经 Agent 直接启动。

> 当前唯一需求基线是工作区根目录《自动选品插件_SkillPlugin形态_定稿_V1.0.md》。本工程是它的实现，不是第 4 份基线。

## 1. 启动

```bash
cd auto-pick-studio
node skills/auto-pick-studio/scripts/start.mjs
```

打开 `http://127.0.0.1:17860/`。服务**只绑 127.0.0.1**，端口为**示例值，待确认**，可用 `AUTO_PICK_PORT=17861` 覆盖。页面零构建、零打包，直接由本机服务提供静态文件。

> **服务是长驻进程：运行它的终端窗口必须一直开着。** 关掉窗口、或在「执行完一条命令就结束」的非交互终端里跑，进程会随会话一起被回收——终端上虽已打印「选品台已启动」，实际已无监听，浏览器就会报「无法访问此网站」。若确实要脱离终端，请用宿主提供的后台任务能力启动，而不是一次性命令。

打不开时按这个顺序自查（不要先猜浏览器或代理）：

| 检查 | 命令 | 正常结果 |
| --- | --- | --- |
| 端口是否在监听 | Windows CMD 下执行 `netstat -ano -p tcp`，再看输出里的 17860 行 | 有 `127.0.0.1:17860 ... LISTENING` |
| 服务是否应答 | `curl --noproxy '*' -o /dev/null -w "%{http_code}" http://127.0.0.1:17860/` | `200` |
| 页面资源是否齐 | 同上，把路径换成 `/style.css`、`/app.js` | 均 `200` |

无监听 = 服务没常驻，回上面重起；有监听但 curl 不通 = 检查 `AUTO_PICK_PORT` 是否被改过；三者都 200 仍白屏 = 再看浏览器控制台。**本机回环不受系统代理影响**：Windows 代理的 bypass 列表默认含 `127.*` 与 `<local>`，无需为它改动设置。

采集需要 Playwright（可选依赖）：

```bash
npm install
npx playwright install chromium
```

未安装或浏览器未下载时，页面与配置、结果功能照常可用，点「采集」会给出明确降级提示，**不会静默失败、不会落库**。

页面是两个 tab：**配置**（站点与账户，低频）和**工作台**（采集 + 结果同屏）。按 `1` / `2` 或 `←` / `→` 切换；顶部状态条跨 tab 常驻，采集完成后自动回到工作台。

## 2. 首次使用顺序

1. 在「配置」tab 新增站点：填站点标识、域名、账户标识、登录页地址（可留空）；**不录入密码，新增默认停用**。
2. 勾选「已核验条款」（逐站核验平台条款是启用前置条件），再点「启用」。
3. 点「登录」→ 会打开一个**有头浏览器窗口**（跨域登录页无法嵌进网页弹框），本人在里面手动输入账号密码或扫码。登录期间系统持续快照 cookies；**关掉窗口即自动保存**，也可回页面点「确认已登录」。结果写到本机 `playwright/.auth/<site>.json`。
4. 回到「工作台」点「采集」，逐站进度与结果同屏可见，不需要跳转。

**每点一次「采集」生成一条采集记录**（开始时间、逐站状态、入库条数、失败原因），收在工作台底部折叠区；点任一轮**原地切换上方结果，不跳详情页**。结果区顶部可切「本轮（默认）/ 全部累计 / 历史轮次」，便利样本说明随视图写「本轮」或「累计」。

登录态过期时，采集前（本地 cookies 有效期）或采集时（被重定向到登录页）会检出，工作台出现**跨 tab 常驻提示**，点「去配置页重新登录」即可回到配置 tab 并高亮该站，重新点「登录」授权。遇到验证码 / 滑块 / 二次验证会暂停该站，**不自动绕过**、也不代填任何密码。点「取消登录」会丢弃本次快照，不覆盖已有登录态。

## 4. B0 真实页面实测（唯一需要你配合的一步）

**状态（2026-11-18 22:4x 更新）**：本人扫码登录生效后，探针拿到了真实商品 DOM，`app/config/site-rules/taobao.json` 已按实测证据**回填 PG-2 搜索结果页**（`status: b0_probe_done`），一次真实采集可入库 48 条。**PG-1 商品详情页仍全部空槽**；值域、价格类型枚举、验证提示词仍是「示例值，待确认」，本轮没有编造任何数字。

**顺序（实测更正）：先本人登录，再跑探针。** 未登录时淘宝搜索结果页只返回骨架屏（实测 110 个 `boneClass_*` 占位、0 个价格文本、正文 141 字），首页也没有真实商品详情页链接，不具备逐字段核对条件；本人登录后同一页面实测为 0 骨架、107 个价格文本、33 个商品链接、48 张卡片。

1. 起服务 → 「配置」tab 新增并启用站点 → 点「登录」→ 本人在有头浏览器手动输入或扫码 → 关窗自动落盘 `playwright/.auth/taobao.json`。
2. 像平时一样搜一次、点开 1～2 个商品页，把地址栏 URL 贴给探针：

```bash
node tools/field-probe.mjs "<真实商品详情页 URL>" 3000
node tools/field-probe.mjs "<真实搜索结果页 URL>" 3000
```

探针**只读**：若本机已有本人登录态则自动复用（`newContext({ storageState })`，不输出 cookie 内容、不代登录、不上传）；输出结构摘要与 `diagnostics.usableForBackfill` 判定。**骨架屏 / 空壳时会明确警告「禁止据此回填任何选择器」**——这是防止把占位 class 当成字段定位的护栏。

| 范围 | 状态 | 说明 |
| --- | --- | --- |
| PG-2 卡片 / 标题 / 商品标识 / 原链 / 店铺 / 价格 / 展示销量 | 已回填 | 48 张卡片逐字段验收，证据登记在规则文件 `_probe_evidence.fields_confirmed` |
| PG-2 图片 / 价格类型 / 序号 / 结果总数、评价数 | 保持空槽 | 未实测到稳定元素，字段态为「未获取」，不填 0、不阻断 |
| PG-1 全部字段 | 保持空槽 | 详情页价格区在 3 次复查中 2 次未渲染，且无商品标识元素；不作为采集入口 |
| 值域 / 价格类型枚举 / 验证提示词 | 保持占位 | 未实测，不编造 |

商品详情链接位于卡片外层 `A` 元素上、卡片内没有承载商品标识的元素，因此 `field_attr_map` 用两个声明式派生值 `$url:id` 与 `$url:canonical`，只从本次真实页面读到的 `href` 中取 `id` 参数。**未登记在 `_probe_evidence.fields_confirmed` 的字段不得回填**；分层自检第 ⑧ 项会逐个比对已填选择器与证据登记表。`app/config/runtime.json` 里的超时与轮询间隔同样是**示例值，待确认**。

## 5. 数据与护栏

| 项 | 落点 |
| --- | --- |
| 业务数据 | `data/store.json`（本机 JSON，原子写 + 串行写锁，`schemaVersion=2`） |
| 密码 | **不存在**：不录入、不传输、不落盘；服务端站点字段白名单会丢弃密码类字段 |
| 登录态 | `playwright/.auth/*.json`（含敏感 cookies，不入库、不上传、不分发） |

以上路径全部在 `.gitignore` 里。护栏：只采公开字段、不采 PII、用本人登录态且不绕验证码风控、串行 + 单站超时 + 失败不轰炸重试 + 每站可启停、仅自用本地留存不转售。旧版若曾生成 `data/credentials.enc` 或 `data/.key`，新版**不再读取**，可自行删除。

## 6. 防错与选品口径

- 每条记录带 `source / as_of / is_estimate`；抓不到的字段标「未获取」，不猜测、不填 0、不阻断。
- 结果区显示便利样本说明（分母 / 时间范围 / 样本量），并提示「展示销量 ≠ 真实销量、采购量 ≠ 销量」。
- 领先标的（被代拍的品）是一等维度、默认参与排序；提供「临时关闭领先优先」与「反例视图」反制锚定偏差；刷新页面恢复默认。
- 不生成综合分、不输出销量预测；选品结论由本人判断。
- 删除进可恢复区；清空是唯一二次确认且为行内；清空不清除可恢复区，`Ctrl/⌘+Z` 或「恢复」可救回；恢复为追加事件 + 重新投影，不覆盖原记录。

## 8. 已知边界

- M1 只启用淘宝一个站；多站维护能力已做，但新站须「条款核验 + 规则实测回填 + 本人显式启用」才进采集队列。
- 导出 `.xlsx`、多期快照与扩散观察、指纹去重、海外站点在 M2 / M3。
- 登录态文件含可冒充本人的敏感信息，请自行管好本机文件权限；不要把它提交到任何仓库。
- 站点规则里 `challenge_hints` 为空时，采集器**不做**验证码特征判定（不虚构特征），只在浏览器抛错时按错误类型标记并暂停。
- 本工具不替代你的选品判断，也不替你做决定；示例数据、文案与阈值均为占位。
