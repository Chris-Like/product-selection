# 选品台（Auto Pick Studio）

选品台是一个本机运行的商品研究工具。想买某样东西，可以从需求出发找候选、按预算比较并打开商品原页核对。想找能卖的商品，可以在 Codex 或 WorkBuddy 中请 AI 梳理方向，再用专业工作台核验数据。

| 入口 | 适合做什么 |
| --- | --- |
| 智能选品助手 | 用一句话描述需求，查看 AI 推荐的搜索词，确认后采集，再发起下一次选品。 |
| 专业工作台 | 手动编排采集计划，查看本轮和历史结果，按需要使用国内零售、FastMoss 或 LinkFox。 |
| 基础配置 | 选择 AI 宿主和分析方式，管理采集站点及登录授权。 |

## 快速启动

在项目根目录中运行。使用 Node.js 20 或更高版本及 npm。

```bash
npm install
npm start
```

启动后打开 [智能选品助手](http://127.0.0.1:17860/assistant.html) 或 [专业工作台](http://127.0.0.1:17860/)。请保持运行服务的终端打开。服务监听本机回环地址。

如果要使用浏览器采集或站点登录，在项目根目录安装 Chromium。

```bash
npx playwright install chromium
```

端口被占用时，可在 PowerShell 中改用其他端口。打开页面时也要使用新端口。

```powershell
$env:AUTO_PICK_PORT = '17861'
npm start
```

## 用智能选品助手找商品

首次使用，在「基础配置 → 选品分析方式」选择「Agent 协作」，再选择 Codex 或 WorkBuddy，并在对应宿主中准备好本项目的 Skill。Codex 可参考[项目插件清单](.codex-plugin/plugin.json)和 [Skill 说明](skills/auto-pick-studio/SKILL.md)。WorkBuddy 的安装步骤见 [WorkBuddy 安装说明](hosts/workbuddy.md)。

以买 20 元以内的文具为例。

1. 打开「智能选品助手」，输入「我想买 20 元以内的文具，优先考虑笔记本和中性笔。」
2. 在所选 AI 宿主打开并发送需求。WorkBuddy 未配置预填链接时，可复制需求到新对话。
3. AI 会整理需求、推荐搜索词并给出「打开需求卡」链接。打开卡片核对预算和搜索词，例如「A5 笔记本」「中性笔套装」。可以直接编辑搜索词，或点「上一步」修改需求。
4. 确认后点「开始采集」。需求卡当前使用淘宝搜索结果页采集，每个搜索词查看第一页。采集前如有站点设置提示，按提示完成配置后可沿用本轮需求。
5. 查看采集状态、商品观察条数和预算分组。有数据时，点「查看本轮商品明细」。结果下方可在「再找一个商品」输入新的需求，开启独立任务。

## 用专业工作台取数和比较

### 国内零售

在「专业工作台 → 国内零售」按手头的数据选择方式。

- **淘宝联盟接口。** 开通权限并配置后，输入最多三个搜索词和可选预算，点击「查询国内商品」。结果来自淘宝联盟推广商品池，价格按联盟估价展示。
- **CSV 导入。** 将授权导出的数据另存为 UTF-8 CSV，至少提供标题以及商品链接或商品 ID。选择文件后填写数据来源、站点和观察日期，再点「导入候选」。表头示例为 `title,price,currency,price_type,spec,url,id`。
- **商品原页核验。** 从已有候选打开原页，核对当前规格、运费和优惠。页面展示价或联盟估价只供比较，实际支付金额以结算页为准。

### FastMoss 和 LinkFox

| 模块 | 适用场景 | 使用方式 |
| --- | --- | --- |
| FastMoss 趋势 | 查看 TikTok Shop 特定市场和时间段的商品表现。 | 在已授权的 Codex 或 WorkBuddy 中使用 FastMoss，要求将结果保存到选品工作台，再查看「FastMoss 趋势」。 |
| LinkFox 选品与货源 | 查看跨境商品或寻找 1688 货源。 | 在已授权的宿主使用对应 LinkFox 工具，回传后到「LinkFox 选品与货源」查看平台和币种。 |

宿主接入、淘宝联盟凭据和数据回传见[数据源与宿主接入说明](hosts/provider-integrations.md)。

### 手动编排采集计划

1. 在「基础配置」启用已核验条款且已配置采集规则的站点。首次使用或登录过期时，点击「登录」，在打开的浏览器里本人登录，再点「确认已登录」或关闭登录窗口。
2. 在「专业工作台」点击「编辑计划」，填写搜索词。按需补充预算、研究场景、关注点和反例，再点「生成计划草案」。
3. 检查后点击「确认并设为生效计划」，回到「当前生效计划」点击「开始采集」。
4. 在「选品结果」查看本轮、全部累计或历史轮次。预算按可比价格分组，缺价记录单独展示。同一商品可能出现在多个查询里，商品观察条数可能包含重复商品。

## 常见问题

| 遇到的问题 | 怎么处理 |
| --- | --- |
| 页面打不开 | 确认启动服务的终端仍在运行，浏览器地址与终端提示的端口一致。 |
| 助手没有进入 AI 对话 | 检查是否已开启「Agent 协作」，所选宿主是否已安装本项目 Skill。WorkBuddy 可使用复制需求方式继续。 |
| 采集提示未登录或浏览器组件缺失 | 回「基础配置」重新授权，或安装 Chromium 后重试。 |
| 淘宝联盟查询提示缺少授权 | 按[接入说明](hosts/provider-integrations.md)配置后重启服务。也可以先用授权导出的 CSV。 |

业务数据保存在本机 `data/store.json`。站点登录态保存在 `playwright/.auth/`，其中可能包含有效会话，请勿提交到仓库。站点登录在平台页面中完成，选品台无需录入密码。
