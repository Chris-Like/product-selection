# 选品台 · 口径速查

> 完整口径见工作区根目录《自动选品插件_SkillPlugin形态_定稿_V1.0.md》。本页只放调用时最容易搞错的几条。

| 主题 | 口径 |
| --- | --- |
| 形态 | Agent Skill / Plugin 包 + 本机 Web 页面（不是 Chrome 扩展、不是公网服务） |
| 双宿主 | WorkBuddy 装 `SKILL.md`；Codex 装 `.codex-plugin/plugin.json`；共用同一 `app/` 与启动脚本 |
| 双触发 | 页面按钮 / Agent 脚本 → 同一 `submit()` → 命令总线（串行 + 幂等 + 落盘重放） |
| 凭据 | 登录态优先；页面维护站点与账户，密码仅登录态重建时用且加密落盘、可一键关闭 |
| 验证码 | 不自动绕过；暂停该站 + 页面提示人工登录一次 |
| 调度 | 串行逐站；单站超时；失败标记不整批失败；不轰炸重试；每站可启停 |
| 数据 | 只采公开字段、不采 PII、仅自用本地留存、不转售；每条带 `source / as_of / is_estimate` |
| 选品 | 本人判断；不生成综合分、不给销量预测；领先标的一等维度、默认参与筛选排序 |
| 防错 | 便利样本说明、字段级「未获取／值异常」、反例视图、一键临时关闭领先优先、决策留痕不可改 |
| 阈值 | 一律「示例值，待确认」；B0 真实页面实测后回填，不照抄公开行业数字 |
| 选择器 | `app/config/site-rules/*.json` 为空槽（`pending_b0_probe`）；未回填走降级态、不落库、不猜测 |
| 可逆 | 删除进可恢复区；清空排除可恢复区；恢复为追加事件 + 重新投影，不覆盖原记录 |
| M1 | 淘宝一个站；多站维护能力先做但只启用 1 站；导出 Excel、多期快照、海外站点在后 |
